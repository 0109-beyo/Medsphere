# MedSphere

A study app for medical students (Anatomy, Physiology, Medical Biochemistry) with an AI tutor powered by OpenAI.

## Get it live for free (no coding required for this part)

### Step 1 — Put the code on GitHub (free)
Already done if you're reading this on GitHub!

### Step 2 — Deploy to Vercel (free)
1. Go to vercel.com and sign up using your GitHub account (free, no credit card required).
2. Click "Add New Project".
3. Select your `medsphere` repository and click "Import".
4. Leave all settings as default and click "Deploy".
5. In about a minute you'll get a live link like `medsphere.vercel.app`.

### Step 3 — Add your OpenAI key
1. Go to platform.openai.com, sign up, and create an API key (under API Keys in settings).
2. Back in Vercel, open your project → Settings → Environment Variables.
3. Add a variable named `OPENAI_API_KEY` and paste your key as the value. Save.
4. Go to the Deployments tab and click "Redeploy".

## Buying a real domain later (optional, not free)
Buy from Namecheap or similar (~$8–15/year), connect it in Vercel under Project Settings → Domains.
